# Issue tracker: GitHub

Issues and specs live in `mrbam88/bamware-brewdesk-flutter`. Use `gh` for all
issue operations.

Every actionable ticket must also be added to Bamware Project 2 and receive
Status, Priority, Area, Size, and Worker fields per
`bamware-ai/skills/board-ops`.

## Conventions

- Create, read, comment on, label, and close issues with `gh issue`.
- PRs as a request surface: no.
- When a skill says "publish," create a GitHub issue.
- When a skill says "fetch the relevant ticket," read the issue and comments.
- GitHub issue dependencies are the canonical blocking-edge representation.
